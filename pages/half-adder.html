IC 7486 + 7408 Gate-Level Arithmetic

Half Adder

The Half Adder is the simplest binary addition circuit. It accepts two 1-bit inputs (A and B) and produces two outputs: the Sum (S) computed by an XOR gate (IC 7486) and the Carry (C) computed by an AND gate (IC 7408). It cannot handle a carry-in, which is why it is called "half" — the full adder extends it.

Input A Active-High

A (Bit 0)

First single-bit operand. Connects to both the XOR (IC 7486) and AND (IC 7408) gates.

Input B Active-High

B (Bit 1)

Second single-bit operand. Also fans out to both logic gates.

Sum Output XOR (7486)

S = A ⊕ B

High when exactly one input is high. Represents the least-significant bit of the addition result.

Carry Output AND (7408)

C = A · B

High only when both inputs are high (1+1=10₂). This carry propagates to the next significant bit.

Enable

No Enable

Pure gate logic — no strobe or enable pin. Outputs are always combinationally driven by A and B.

Boolean Expression & Logic Equations

The Half Adder produces two canonical SOP expressions, one for each output:

S = A'B + AB'   = A ⊕ B   (XOR — IC 7486)
C = AB                     (AND — IC 7408)

S is HIGH for minterms Σm(1, 2) — when exactly one input is 1.
C is HIGH for minterm Σm(3) — only when both inputs are 1 (the binary value 2).

Practical Applications

Where the Half Adder structure appears in real digital systems.

LSB Stage of Ripple-Carry Adders

In an n-bit ripple-carry adder, the least-significant bit position uses a half adder (no carry-in possible), while all subsequent positions use full adders that accept carry-in from the previous stage.

Building Block of the Full Adder

Two half adders cascaded with an OR gate form a full adder. Understanding the half adder is therefore a prerequisite for understanding ripple-carry arithmetic used in the IC 7483 4-bit binary adder.

Binary Counters & Incrementers

A half adder can increment a single bit by one. Chaining them (with the carry output feeding the next bit's XOR) produces a parallel binary incrementer, which is used in program counters and address generators.

ALU Design

Arithmetic Logic Units in microprocessors are built from arrays of half and full adders. The sum and carry signals feed into carry-lookahead logic for high-speed computation.
