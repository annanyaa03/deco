IC 7483 ref. 3-input 1-bit Adder

Full Adder

The Full Adder extends the Half Adder to accept a Carry-in (Cin), making it chainable for multi-bit addition. It takes three 1-bit inputs (A, B, Cin) and produces a Sum (S) and Carry-out (Cout). Internally it is built from two half adders (each an XOR + AND pair) plus an OR gate. The IC 7483 packages four full adders in a single 16-pin DIP chip for 4-bit ripple-carry addition.

Input A Active-High

A (Bit 0)

First single-bit operand. Feeds into the first half adder (HA1).

Input B Active-High

B (Bit 1)

Second single-bit operand. Also feeds into HA1 alongside A.

Carry-In Active-High

Cin (Carry in)

Incoming carry from a lower-order bit stage. Feeds into the second half adder (HA2).

Sum Output XOR chain

S = A ⊕ B ⊕ Cin

Three-input XOR result. High when an odd number of inputs are high.

Carry-Out Active-High

Cout = AB + Cin(A⊕B)

Carry generated or propagated. Drives the Cin of the next higher-order full adder stage.

Boolean Expressions & Logic Equations

Canonical Sum-of-Products (minterm notation):

S = Σm(1, 2, 4, 7) = A ⊕ B ⊕ Cin
Cout = Σm(3, 5, 6, 7) = AB + BCin + ACin

Simplified form with internal signals visible in the simulator:
Let P = A ⊕ B (propagate — output of HA1)
Let G = A · B (generate — carry of HA1)
Then: S = P ⊕ Cin  &&  Cout = G + Cin · P

Practical Applications

Where full adder cells appear in digital hardware.

Ripple-Carry Adders (IC 7483)

The IC 7483 chains four full adder cells in a 16-pin DIP, enabling 4-bit binary addition. Carry-out of each cell ripples into the Cin of the next, allowing cascading to 8, 16, or 32-bit widths.

Arithmetic Logic Units (ALUs)

Every ALU in every CPU uses a tree of full adder cells. Modern designs use carry-lookahead or carry-select structures built on the same propagate/generate logic derived from the basic full adder.

Address Calculation

Program counters, stack pointers, and memory address generators all increment or offset addresses using cascaded full adders, incrementing by 1 each clock cycle.

Binary Multipliers

Array multipliers use rows of full adders to accumulate partial products. Each row shifts and adds, producing the final product via a Wallace tree of full adder carry-save stages.
