IC 74180 9-bit Odd/Even Parity

9-bit Parity Generator / Checker

The IC 74180 is a 9-bit odd/even parity generator and checker. It accepts 8 data inputs (A–H) and two cascade control inputs (EVEN and ODD), and produces dual complementary outputs (ΣEVEN and ΣODD). Internally it implements an XOR reduction tree: the parity of A through H is XORed with the cascade inputs, making the device cascadable to handle 16-bit, 32-bit, or wider words.

Generator vs Checker Mode

As a Generator: Connect 8 data bits to A–H, set EVEN=1 ODD=0. ΣEVEN goes HIGH if the data has even parity — this bit is appended to the data word for transmission.

As a Checker: Connect 8 data bits + the received parity bit (9 bits total, spread across A–H and one cascade input). If ΣEVEN=L and ΣODD=H, a single-bit error has occurred in transmission.

Data Inputs Active-High

A, B, C, D, E, F, G, H

8 data bits whose XOR reduction determines the raw parity value fed into the cascade logic.

Cascade EVEN Active-High

EVEN input

Set HIGH to assert even-parity convention. If both EVEN and ODD are the same (both H or both L), a special forced-output mode activates.

Cascade ODD Active-High

ODD input

Set HIGH to assert odd-parity convention. In normal operation, EVEN and ODD are complements of each other.

ΣEVEN Output Active-High

ΣEVEN

HIGH when the combined parity of A–H plus cascade inputs produces an even total count of 1s.

ΣODD Output Active-High

ΣODD

HIGH when the combined parity produces an odd total count of 1s. Always the complement of ΣEVEN in normal mode.

Boolean Expression & Logic Equations

The raw data parity is computed by XOR reduction of all 8 data bits:

P = A ⊕ B ⊕ C ⊕ D ⊕ E ⊕ F ⊕ G ⊕ H

ΣEVEN = P ⊕ ODD    (= NOT(P ⊕ EVEN))
ΣODD = P ⊕ EVEN  (= NOT(P ⊕ ODD))

Special cases:
If EVEN = ODD = H → ΣEVEN = ΣODD = L
If EVEN = ODD = L → ΣEVEN = ΣODD = H

In normal operation EVEN and ODD are always complementary. ΣEVEN and ΣODD are always complementary outputs, making the IC useful as both a generator (produce one parity bit) and a checker (detect errors with the complementary output).

Practical Applications

Where parity generation and checking is used in digital systems.

Memory Error Detection

DRAM and SRAM memory systems append a parity bit per byte. On read, the 74180 recomputes parity across all 9 bits (8 data + stored parity). A mismatch on ΣODD flags a single-bit error.

Serial Communication (UART Parity)

UART/RS-232 interfaces transmit an optional parity bit after each data byte. The 74180 computes even or odd parity for the data bits, and the receiver uses an identical circuit to check every byte.

Bus Integrity Checks

Address and data buses in embedded systems use 74180 circuits to monitor signal integrity. Any even-count corruption on a normally-odd bus immediately asserts an error flag to the processor.

Cascading for 16+ bit Words

By chaining two 74180 ICs via their cascade inputs (ΣODD of one feeds ODD of the next), 16-bit, 32-bit or wider parity can be computed and checked with no additional delay beyond propagation.
